# Planning – ELSE-labb

## Produktidé

Vår idé var att vi skulle bygga en FullStack Todo app med ett tillhörande API. Detta då vi upplevde att det både var
ett simpelt projekt som kunde göras under tidsramen och hjäpa alla gruppmedlemmar att öva på de områden de kände sig
osäkra på.

## User stories

- Som användare vill jag kunna logga in med användarnamn och lösenord så jag kommer in på startsidan
- Som utvecklare vill jag skapa en databas så att jag kan lagra, läsa och ändra data för ett ToDo Api
- Som en användare vill jag kunna spara todos som jag behöver göra under dagen.
- Som en användare vill jag kunna bocka i ett todo objekt när den är klar.
- Som en användare vill jag kunna ta bort todo objekt som inte längre är relevanta.

## Prioriterad backlog

1. Sätta upp en fungerande DB
2. Starta upp BE och koppla den till DB
3. Skapa enteties och endpoints för API:et
4. Aktivera CORS och sätta upp brandväggs regler för DB
5. Starta upp FE och koppla det till BE
6. Skapa sidor i FE
7. Skapa komponenter och funktioner i FE
8. Testing
